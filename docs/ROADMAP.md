# Roadmap

| Milestone | Scope | Status |
|---|---|---|
| **M1 Core API** | Auth, onboarding gates, matching, escrow flow, licensing affidavits, safety, POPIA endpoints, tests | **Done** |
| **M2 Client** | Wire the clickable prototype to this API (mobile-first web app or React Native). Screens: sign-in, onboarding, post, offers, pay, deal tracker, affidavits, meetup safety, wallet statement | Next |
| **M3 Real integrations** | Payment provider (linked-account EFT, card via hosted fields, payouts); SMS gateway and push; CIPC and bank-account verification services | |
| **M4 Hardening** | Postgres, encrypted storage for affidavits, CI security scans, penetration test, load test, monitoring and alerts | |
| **M5 Pilot** | One niche, one region (e.g. construction in Gauteng), 20 experts and 20 businesses, measure deal size and drop-off, tune the fee | |
| **Later** | Licensing-deal fee model, FNB business-banking integration, multi-language, staff admin console | |
